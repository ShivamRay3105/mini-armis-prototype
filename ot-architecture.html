OT Security Monitoring Platform – Architecture View

Frontend Layer

React Dashboard

  • Asset Inventory View
  • Risk Scores & Status
  • Alerts Timeline
  • Manual Event Simulation
  • Tech: React, REST APIs
Access & Security Layer

API Gateway

  • Single Entry Point
  • Routing to Microservices
  • JWT Validation
  • Tech: Spring Cloud Gateway

Auth Service

  • User Login / Logout
  • JWT & Refresh Tokens
  • Token Blacklisting
  • Tech: Spring Security, Redis
Core Backend Microservices

Asset Service

  • Device Inventory
  • Protocol Tracking
  • Risk Score Storage
  • Tech: Spring Boot, PostgreSQL

Event Ingestion Service

  • Receives Device Events
  • Simulated OT Activity
  • Publishes Events
  • Tech: REST, Kafka Producer

Risk Engine Service

  • Rule-Based Risk Analysis
  • Protocol & Behavior Rules
  • Risk Score Calculation
  • Tech: Java, Spring Boot

Alert Service

  • Threshold-Based Alerts
  • Event Correlation
  • Real-Time Notifications
  • Tech: Kafka Consumer, WebSocket
Messaging & Data Layer

Kafka (Event Bus)

  • asset-events
  • risk-events
  • alert-events
  • Purpose: Async, decoupled communication

Datastores

  • PostgreSQL – Persistent Data
  • Redis – Cache & Tokens
Simulated OT Environment

Simulated Devices

  • PLCs
  • HMIs
  • RTUs
  • Protocols: Modbus, DNP3
  • No real hardware required

End-to-End Flow

Simulated Device Event
        ↓
Event Ingestion Service
        ↓
Kafka (asset-events)
        ↓
Risk Engine
        ↓
Risk Score Updated
        ↓
Kafka (risk-events)
        ↓
Alert Service
        ↓
WebSocket Notification
        ↓
React Dashboard
